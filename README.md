# 🩺 ЕМИАС Автоперенос записи (Chrome Extension)

[![Manifest V3](https://img.shields.io/badge/Chrome%20Extension-Manifest%20V3-blue.svg)](https://developer.chrome.com/docs/extensions/mv3/intro/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-emias.info-teal.svg)](https://emias.info)

Неофициальное расширение для браузера Google Chrome, позволяющее находить освобождающиеся слоты в расписании врачей на портале [emias.info](https://emias.info/app/einfo/) и автоматически переносить выбранную запись на время, максимально близкое к желаемому.

---

## 📥 Установка за 30 секунд

1. Скачайте репозиторий: нажмите зеленую кнопку **`Code` ➔ `Download ZIP`** и распакуйте архив в удобную папку.
2. В браузере Google Chrome откройте страницу:
   ```text
   chrome://extensions/
   ```
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. В левом верхнем углу нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите распакованную папку.
5. Расширение установлено и готово к работе!

---

## ✨ Возможности

- **🎯 Умный подбор времени**: рассчитывает точную дельту в минутах между целевым временем и доступными талонами, сортируя самые удобные варианты на первое место.
- **⚡ Мгновенный перенос в 1 клик**: просмотр ближайших слотов прямо в интерфейсе с возможностью перенести запись без блуждания по календарю.
- **🚀 Режим авто-снайпера (Мониторинг)**: фоновое отслеживание отмен талонов другими пациентами со звуковым сигналом и мгновенной бронью.
- **🛡️ Защита от блокировок**: случайный плавающий интервал опроса (22–32 секунды) предотвращает подозрительную активность.
- **📲 Уведомления в Telegram**: мгновенный отчёт на телефон об успешном переносе через официальный Telegram Bot API.
- **🔒 Полная приватность**: работает на 100% локально в браузере, не собирает и не отправляет персональные данные на сторонние серверы.

## 🚀 Как пользоваться

1. Откройте страницу [emias.info/app/einfo/](https://emias.info/app/einfo/) (где вы уже авторизованы).
2. Нажмите на иконку расширения в панели браузера (или на плавающий виджет в правом нижнем углу страницы).
3. **Выберите запись** для переноса из выпадающего списка.
4. **Укажите желаемое время** и допустимое окно (±30 мин, ±1 час, ±2 часа или весь день).
5. Нажмите:
   - **«🔍 Найти слоты сейчас»** — для моментального отображения доступных талонов и ручного выбора.
   - **«🚀 Запустить автоперенос»** — для автоматического ожидания отмен и моментального бронирования лучшего слота.

## 📱 Настройка уведомлений в Telegram

1. Создайте своего личного бота в Telegram у [@BotFather](https://t.me/BotFather) (команда `/newbot`) и скопируйте полученный **Bot Token**.
2. Нажмите кнопку **Start** (`/start`) в диалоге с созданным ботом.
3. Узнайте свой цифровой ID у [@userinfobot](https://t.me/userinfobot) (**Chat ID**).
4. В расширении откройте вкладку **«Telegram»**, вставьте оба значения и нажмите кнопку **«Отправить тест»**.

## 🛡️ Безопасность и конфиденциальность

- Расширение **НЕ запрашивает ваши пароли, логины или СНИЛС**.
- Все сетевые запросы отправляются напрямую между вашим браузером и сервером ЕМИАС с использованием вашей существующей авторизованной сессии.
- Исходный код открыт и доступен для аудита прямо в этом репозитории.
