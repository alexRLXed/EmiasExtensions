# Политика конфиденциальности (Privacy Policy)

**Расширение «Помощник переноса записи для emias.info»**

*Дата вступления в силу: 6 сентября 2026 г.*

### 1. Общие положения
Настоящая Политика конфиденциальности описывает, как расширение «Помощник переноса записи для emias.info» (далее — «Расширение») обрабатывает информацию пользователей.

### 2. Сбор и передача данных
- **Мы НЕ собираем персональные данные.** Расширение не собирает, не передает и не сохраняет на сторонних серверах ваши персональные данные, медицинскую информацию, ФИО, номер полиса ОМС, дату рождения или историю посещений врачей.
- **Локальная обработка:** Все операции по чтению расписания и отправке запросов на перенос записи происходят исключительно локально на вашем компьютере внутри вашего браузера Google Chrome.
- **Сторонние серверы:** Разработчик расширения не имеет собственных серверов для сбора статистики или логов.
- **Telegram:** Если вы настраиваете уведомления в Telegram, токен вашего бота и идентификатор чата хранятся локально в хранилище вашего браузера (`chrome.storage.local`). Запросы на отправку сообщений отправляются напрямую с вашего компьютера на официальные серверы Telegram (`api.telegram.org`).

### 3. Разрешения браузера
- `storage`: требуется исключительно для сохранения ваших локальных настроек (желаемое время приёма, настройки Telegram).
- `host_permissions` для `emias.info`: требуется для отправки локальных запросов к API расписания в контексте вашей активной авторизованной сессии.
- `host_permissions` для `api.telegram.org`: требуется для отправки уведомлений в ваш личный бот.
